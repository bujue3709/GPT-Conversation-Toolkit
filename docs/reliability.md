# 长会话与导出回归说明

## 为什么做这些改动

这次改动来自日常使用中的几个问题：Edge 曾频繁关闭全部窗口，排查时观察到较高的内存占用和大量扩展资源活动；导出聊天时又发现图片缺失、等待过程没有反馈。后续实机验证还遇到了会话接口 403，以及页面只挂载少量消息时，时间线丢掉此前已取得的完整历史。

目前能确认并复现的是扩展内的资源放大和功能缺陷，例如文字提取时克隆图片节点、缓存导出丢失图文顺序，以及取消后仍继续翻页。上述现象不能证明每次 Edge 崩溃或 ChatGPT 发送失败都由扩展引起。

## 现在的行为

- **历史记录**：时间线、搜索和导出共用索引。已有 47 条提问时，页面只挂载 6 条不会把完整索引缩成 6 条。刷新失败保留缓存及其更新时间；切换分支时不拼接旧分支的尾部。
- **切换会话**：优先使用 URL 中的会话 ID，避免 React 更新期间读取旧节点的 ID。导航会关闭导出弹窗，并在页面渲染后重新绑定消息区；旧路由迟到的请求结果不会写入新会话。
- **读取失败**：优先请求当前站点的普通会话接口，随后有限尝试分页和兼容接口。单个接口的普通 403 不代表整个会话不可读；明确的 Cloudflare 验证挑战立即停止，429 使用共享冷却。已有缓存仍可导出，并显示时间与完整性；只有页面数据时，需主动选择导出已加载部分。
- **图片与格式**：图片下载默认关闭。开启后，ZIP 只附带所选格式、原图与完整性清单；图文顺序在内存和持久化缓存中保持一致。单页 PNG 直接下载，多页 PNG 合成一个 ZIP，均交给浏览器下载管理器。
- **取消任务**：关闭弹窗会取消导出。共享请求保留其他调用方的读取；最后一个调用方取消后，底层请求和分页一起停止。
- **页面兼容**：搜索用 Range 高亮，不替换 React 管理的文本节点。不支持该 API 的浏览器保留消息外框提示。已停用的自动折叠不再注册全局点击监听或读取记忆；保留旧消息的恢复代码。

资源阈值和归档结构见 [图片导出说明](./image-export.md)。图片并发下载保持在两张以内，ZIP 仍按顺序写入。被动会话捕获最多同时读取两个响应，并共享读取预算；超过限制时跳过捕获，宿主页面的原始响应继续正常读取。

跨世界消息校验发送窗口、来源和字段结构，目标源限定为当前站点。这些校验不提供对同一页面内其他脚本的身份认证。图片地址仅保留在运行时私有属性和本地扩展缓存中，不进入导出图片元数据；缓存中的签名地址仍可能过期。

## 如何验证

```bash
npm ci
npm test
npm run test:browser
npm run package
```

单元测试覆盖共享请求取消、缓存往返、图文顺序、分支替换、迟到响应、47 条历史与 6 条 DOM 消息、403 缓存导出、来源校验及归档资源上限。浏览器测试在独立配置中加载实际扩展，拦截并注入合成会话和图片；覆盖 UI 下载、原图字节、PNG 像素、MAIN 世界导航及消息区替换、搜索零文本节点修改、多页 PNG 单次下载、取消和临时文件清理。

测试使用合成数据，未登录真实 ChatGPT 账号。线上接口和虚拟列表的变动，以及导出后偶发的红色发送错误，仍需在真实账号中验证，不能仅凭这些测试认定已经消除。

## 手动诊断

在开发者工具中，将控制台执行上下文切到本扩展，再执行：

```js
__CGPT_TOOLKIT_INDEX_DEBUG__.summary()       // 索引条数、完整性、更新时间
__CGPT_TOOLKIT_INDEX_DEBUG__.requests()      // 请求类别、脱敏路径、状态与耗时
__CGPT_TOOLKIT_INDEX_DEBUG__.cache()         // 本地索引的条数和时间
__CGPT_TOOLKIT_INDEX_DEBUG__.reload()        // 主动重试，会重新发起请求
```

诊断摘要不包含聊天正文或认证凭据。报告问题时，说明会话类型、导出格式、是否包含图片，以及失败请求的状态即可；无需提供 Token 或带签名的图片地址。
